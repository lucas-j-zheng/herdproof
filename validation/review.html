Four images. Two ways to review.

Mark each visible cow once. Manual trials start empty; assisted trials start with AI markers. Use Add to mark a cow and Remove to delete a marker. Zoom into crowded groups and inspect the entire image before finishing.

Use this tab before opening the reconciliation example. Each trial uses a different flight. Reference labels stay hidden until all four trials are complete. Time pauses while the tab is hidden.
